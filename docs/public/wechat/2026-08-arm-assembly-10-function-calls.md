# 函数调用：让代码学会复用

顺序、分支、循环——前几课我们把程序三大控制流全部打通了。但还差一块拼图：真实程序动辄几十万行，同样的逻辑要在十个地方各写一遍，改一处就得改十处。解决方案你早就用熟了——函数。这一课讲：函数调用在 ARM 汇编层到底发生了什么。

核心只有四个问题：参数怎么递过去？怎么跳过去干活？算完怎么回来？回来时怎么保证寄存器没被弄乱？

## 一个最小的函数调用

先看 C 代码：

```c
int addNums(int a, int b) {
    return a + b;
}

int main() {
    int result = addNums(1, 2);
}
```

翻译成 ARM 汇编，调用方和被调方各干各的活：

![图 1 · C 的函数调用与 ARM 汇编逐行对照](/assets/images/2026-08-arm-assembly/fig-func-map.png)

调用方（main）负责三件事——备参数、发起调用并接住返回值、护现场。被调方（add_nums）只负责干活和回家。

> **注：**"现场"指调用前各寄存器里的值。add_nums 会把 r0 改成结果，调用方还想要 r0 的旧值，就得调用前先存起来。

## 怎么跳过去、怎么回来

跳过去靠 `bl add_nums`（Branch with Link），一条指令干两件事：先把"下一句指令的地址"写进 LR 寄存器（R14 的别名），然后跳到 add_nums 标签处。

回来靠 `bx lr`：把 LR 里的地址装回程序计数器，CPU 就回到了当初 bl 的下一句。

![图 2 · 函数调用流程：BL 跳入，BX LR 返回](/assets/images/2026-08-arm-assembly/fig-func-flow.png)

"留地址—回地址"是函数调用的命脉。没有 LR，跳过去就回不来了——出门不记家门地址，干完活只能流浪。

> **易错点：**被调方内部若再调用别的函数，第二条 bl 会覆盖 LR，第一个返回地址就丢了。所以嵌套调用时，函数进来先 push {lr}，返回前 pop {lr}。本课例子没有嵌套，暂不用管。

## 参数与返回值：调用约定

参数放哪、结果放哪，不是双方临时商量的，而是体系结构提前定好的规矩——调用约定（calling convention）。ARM 的约定一句话：参数从 r0 开始递，返回值也用 r0 还。

![图 4 · 调用约定速查：寄存器角色分工](/assets/images/2026-08-arm-assembly/fig-func-regs.png)

前 4 个参数依次放 r0~r3，第 5 个及更多压栈；返回值放 r0。所以调用方在 bl 之后从 r0 取结果，例子里用 `mov r2, r0` 转存。

也正因为返回值固定放 r0，而 r0 同时是第一个参数寄存器——add_nums 一执行 `add r0, r0, r1`，参数就被结果顶掉了。这就引出最后一环。

## 护现场：PUSH / POP 与栈

调用前 r0=1、r1=2 是调用方还在用的值，函数一跑 r0 变成 3，原值没了。办法：调用前把怕丢的寄存器 `push {r0, r1}` 压进栈，SP（栈指针）自动挪到新栈顶；回来 `pop {r0, r1}` 后进先出地弹回，SP 退回原位。

![图 3 · 栈的三连拍：push 前 / push 后 / pop 后](/assets/images/2026-08-arm-assembly/fig-func-stack.png)

栈就是一块"谁都能临时寄存行李的格子架"，函数调用全靠它保平安。

> **关键性质：push 和 pop 必须配对。**寄存器列表一致、顺序匹配。只 push 不 pop 栈就漏了；只 pop 不 push 取回的是垃圾值。

## 完整走一遍

1. `mov r0, #1` / `mov r1, #2`——按约定放参数
2. `push {r0, r1}`——值 1 和 2 进栈，护住现场
3. `bl add_nums`——LR 记下返回地址，跳进函数
4. `add r0, r0, r1`——r0 = 1 + 2 = 3，结果放回 r0
5. `bx lr`——返回，落到 `mov r2, r0`
6. `mov r2, r0`——返回值 3 转存 r2
7. `pop {r0, r1}`——1 和 2 弹回，r0、r1 恢复原样

r2=3（拿到结果），r0、r1 原封不动（现场无损），SP 复位（栈干净）——教科书式的函数调用。

## 小结

- 函数调用四件事：传参（r0~r3）、跳转（bl）、返回（bx lr）、护现场（push/pop）
- bl 一条指令干两件事：LR ← 返回地址，然后跳转；bx lr 按地址回家
- 调用约定：第 1~4 个参数依次放 r0~r3，更多压栈；返回值放 r0
- push 存值进栈、SP 挪到新栈顶；pop 后进先出恢复、SP 复位；两者必须配对
- 嵌套调用会覆盖 LR，函数套函数时要 push {lr} / pop {lr}
