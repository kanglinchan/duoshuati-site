# 第 137-138 课：A Pleasant Dream

> [新概念英语 · 第一册 英语初阶](/nce/ "返回目录")

A pleasant dream<br><span class="zh">一个美好的梦想</span>

Listen to the tape then answer this question.<br><span class="zh">请听完录音后回答这个问题：</span>

What would Julie like to do, if she had the money?<br><span class="zh">如果朱莉有钱，她想做什么？</span>

Are you doing the football pools, Brain?<br><span class="zh">你在填足球彩票吗，布莱恩？</span>

Yes, I've nearly finished, Julie.<br><span class="zh">是的，我快完成了，朱莉。</span>

I'm sure we'll win something this week.<br><span class="zh">我肯定我们这周会中奖的。</span>

You always say that, but we never win anything!<br><span class="zh">你总是这么说，但我们从来都没赢过！</span>

What will you do if you win a lot of money?<br><span class="zh">如果你赢了很多钱，你会做什么？</span>

If I win a lot of money I'll buy you a mink coat.<br><span class="zh">如果我赢了很多钱，我会给你买一件貂皮大衣。</span>

I don't want a mink coat!<br><span class="zh">我可不要貂皮大衣！</span>

I want to see the world.<br><span class="zh">我想去看看这个世界。</span>

All right.<br><span class="zh">好的。</span>

If we win a lot of money we'll travel round the world and we'll stay at the best hotels.<br><span class="zh">如果我们赢了很多钱，我们就环游世界，住最好的酒店。</span>

Then we'll return home and buy a big house in the country.<br><span class="zh">然后我们就回家，在乡下买一座大房子。</span>

We'll have a beautiful garden and...<br><span class="zh">我们将拥有一个美丽的花园，还有……</span>

But if we spend all that money we'll be poor again.<br><span class="zh">但是如果我们把所有的钱都花掉了，我们又会变得穷困了。</span>

What'll we do then?<br><span class="zh">那我们该怎么办呢？</span>

If we spend all the money we'll try and win the football pools again.<br><span class="zh">如果我们把所有的钱都花光了，我们就再试着去赢足球彩票。</span>

It's a pleasant dream but everything depends on 'if' !<br><span class="zh">这真是个美梦，但一切都取决于'如果'！</span>
