# 数学笔记 · 导读

这个专栏记录我重新整理中学数学的过程。目标很简单：把每个专题拆成三件事——什么时候用、怎么用、哪里容易错。

### 为什么单独开一栏

写代码久了容易产生一种错觉：数学题难在计算。真正难的是选择。

会背求根公式，不代表看到 $x^2-5x+6=0$ 会先想到因式分解；会背平方差，不代表遇到 $x^4-16$ 能想到"还要再拆一次"。这跟写程序很像：记住所有函数名，不等于知道该在什么时候调用哪个。

所以这里的每一篇都不按教科书顺序讲知识点，而是按"拿到题先干什么"来组织。

### 这门笔记怎么写

每篇结构固定：

1. 这个方法解决什么问题，不用它会怎样；
2. 判断顺序——先看什么、再看什么；
3. 例题，给完整过程，不写"易得""显然"；
4. 章末自测，做错直接显示解析。

公式用 LaTeX 排版，推导尽量一步一行。系列文章会互相引用，但每篇都能单独读懂。

### 两条约定

第一，只讨论有理数范围内的分解。同一个式子在不同数域里结果不同，比如 $x^4-4$ 在有理数范围只能拆到 $(x^2+2)(x^2-2)$，到了实数范围还能继续。本文不越界。

第二，每篇末尾都有自测题。题目不难，但都针对正文里的易错点，建议先做再往下看别的。

**前置要求**：会整式乘法，知道 $(a+b)(c+d)=ac+ad+bc+bd$ 怎么展开，就够了。
