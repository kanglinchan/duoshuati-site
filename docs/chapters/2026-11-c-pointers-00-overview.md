# C 指针 · 导读：写给前端开发者

这门课提炼自《征服C指针（第2版）》（前桥和弥），砍掉 C 语言历史、编译器细节等支线，只保留指针主线，重写成 9 篇通俗易懂的笔记。

### 为什么前端要学 C 指针

先想一个你肯定遇到过的问题：JS 里这段代码为什么输出 60？

```js
const a = { score: 100 };
const b = a;
b.score = 60;
console.log(a.score);   // 60？我明明改的是 b
```

答案是"b 存的不是对象，是对象的地址（引用）"。这个"引用"，就是 C 里的指针——只不过 JS 把它藏起来了，而 C 把它直接交到你手上。

学 C 指针，对前端至少有三个立竿见影的好处：

- **看懂 JS 的底层**：对象引用、原型链、浅拷贝深拷贝、`Array.push` 的扩容……这些在 C 里都是明码标价的指针操作。懂了 C 再看 JS，到处是"哦原来如此"。
- **打通计算机基础**：栈和堆、内存泄漏、缓冲区溢出——面试常问、日常调 bug 也常遇到的词，在 C 里全是具象的操作。
- **为进阶铺路**：想碰 Node 扩展、WebAssembly、V8 源码，C 指针是绕不开的门票。

### 这门课怎么讲

作者在前言里说了一句很提气的话：

> **理解不了 C 指针不是你的错，是 C 语言的语法太坑人了。**

确实如此。C 指针难，难在两个地方：一是声明写法反直觉（`int *a[10]` 怎么读？），二是数组和指针黏黏糊糊分不清。这门课就围绕这两个难点，一层层拆开讲。

每课配了内存示意图和章末自测题，建议按顺序读。
