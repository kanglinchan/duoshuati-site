# C 指针第一课：先搞懂指针到底是什么

![指针变量保存的是地址：hoge_p 指向 hoge](/assets/images/c-pointers/cptr-01-pointer.png)

如果你写过 JavaScript，一定遇到过这个现象：

```js
const a = { score: 100 };
const b = a;
b.score = 60;
console.log(a.score);  // 60 —— 改 b 怎么把 a 也改了？
```

原因很简单：`b = a` 复制的不是对象本身，而是**对象的地址**。a 和 b 存的是同一个地址，指向同一块内存，所以改谁都一样。

在 JS 里，这个"地址"被语言藏起来了，你摸不着它。而 C 语言做了一件大胆的事：把地址直接暴露给你，让你亲手拿着用。这个"拿在手里的地址"，就是指针。

这一课我们只解决三件事：指针到底是什么、`&` 和 `*` 这两个符号干什么用、指针的第一个实际用途。读完你就能写出第一段真正用到指针的 C 代码。

提前声明边界：这一课不涉及 C 语言最让人头疼的声明语法（比如 `int *a[10]` 到底怎么读），那是第 5 课的事。这里只需要会用最基本的形式。

### 1. 内存：一排带编号的格子

先建立一个心智模型。

计算机的内存（Memory），可以想成一排巨大无比的储物柜。每个柜子能装 1 字节（byte）的数据，柜子从 0 开始挨个编号。这个编号，就叫**地址（address）**。

一个 int 类型的数需要 4 个柜子才能装下，一个 char 只需要 1 个。你在程序里声明一个变量，本质就是向系统申请几个连在一起的柜子，而变量的"门牌号"就是它第一个柜子的编号。

```c
int hoge = 5;    /* 占了 4 个连着的柜子，比如 0x100~0x103 */
char c = 'A';    /* 占 1 个柜子 */
```

不同类型的变量占几个字节，可以用 `sizeof` 运算符问出来：

```c
printf("%zu\n", sizeof(char));    /* 1 */
printf("%zu\n", sizeof(int));     /* 4（大多数环境） */
printf("%zu\n", sizeof(double));  /* 8 */
```

记住一句话：**变量住在内存里，每个变量都有地址。**

### 2. 指针：专门存地址的变量

现在请出主角。

**指针（pointer）是一种变量，它存的内容不是普通的数，而是另一个变量的地址。**

```c
int hoge = 5;      /* 普通变量，存整数 5 */
int *hoge_p;       /* 指针变量，专门存"int 变量的地址" */

hoge_p = &hoge;    /* 把 hoge 的地址存进去 */
```

`int *hoge_p` 这个写法读作"hoge_p 是一个指向 int 的指针"。声明里的 `*` 表示"这是个指针"，`int` 表示"它指向的东西是 int 类型"。

第三行的 `&hoge` 是**取地址**运算符，意思是"把 hoge 的门牌号给我"。执行完这一行，hoge_p 里面存的就是 hoge 的地址。这时我们说：**hoge_p 指向 hoge**。

回到开头的图再看一遍：hoge 这个格子里装着 5，hoge_p 这个格子里装着 hoge 的地址 `0x7ffe…e80`，中间那根箭头就是"指向"关系。

那么，存了地址有什么用？接着看。

### 3. `*`：顺着地址摸到那个变量

**在指针前面加 `*`，就能摸到它指向的那个变量**，读它的值、改它的值都行。这个操作叫**解引用（dereference）**——顺着引用找到本体。

```c
int hoge = 5;
int *hoge_p = &hoge;   /* 声明的同时初始化：让 hoge_p 指向 hoge */

printf("%d\n", *hoge_p);  /* 5 —— 读出 hoge 的值 */

*hoge_p = 10;             /* 改 hoge 的值 */
printf("%d\n", hoge);     /* 10 */
```

关键认知：**只要 hoge_p 指向 hoge，`*hoge_p` 就和 `hoge` 完全等价**。`*hoge_p` 读出来是 hoge 的值，往 `*hoge_p` 里写就是写进 hoge。

这里有个容易混的地方，多看一眼：

- **声明时**的 `int *hoge_p`：`*` 是"这是指针"的标记，声明的变量叫 `hoge_p`。
- **使用时**的 `*hoge_p`：`*` 是"解引用"运算符，意思是"摸到指向的东西"。

同一个符号两种身份，这是 C 语言混乱的源头之一，第 5 课会彻底拆解。现在先记住：声明里的 `*` 归类型管，表达式里的 `*` 归运算符管。

### 4. 地址长什么样？

想亲眼看看地址，用 `printf` 的 `%p` 格式：

```c
int hoge = 5;
int *hoge_p = &hoge;

printf("&hoge   = %p\n", (void*)&hoge);    /* 0x7fffe0848e80 之类 */
printf("hoge_p  = %p\n", (void*)hoge_p);   /* 和上面一模一样 */
printf("&hoge_p = %p\n", (void*)&hoge_p);  /* 指针自己也有地址！ */
```

三个细节值得停一下：

**第一，地址是十六进制的大数字。** 每次运行都不一样（系统会随机化），别背数值，看关系。

**第二，`hoge_p` 的值就是 `&hoge`。** 这不正是"指针变量存地址"的直接证据吗？

**第三，指针变量自己也住在内存里，也有自己的地址**（`&hoge_p`）。指针是变量，变量的待遇它一样不少。

> **注意：** `%p` 要求参数是 `void*` 类型，所以代码里写了 `(void*)` 做转换。`void*` 是"什么都能指"的通用指针，第 4 课还会遇到它。现在照抄即可。

### 5. NULL：明确表示"哪儿也不指"

指针声明了但还没让它指向任何东西时，它里面是个**不确定的垃圾值**——碰巧指到某个地址，程序就可能写出莫名其妙的 bug。

C 提供了一个明确表示"哪儿也不指"的特殊值：**NULL（空指针）**。

```c
int *p = NULL;          /* 先让它指向"空" */

if (p != NULL) {
    printf("%d\n", *p); /* 确认有效才用 */
}
```

用 NULL 初始化指针是个好习惯：如果不小心解引用了它，操作系统会立刻把程序毙掉（就是那个著名的"段错误"），bug 当场暴露。而野指针指到随机地址，可能悄悄把别的数据写坏，程序还若无其事地跑——这种 bug 才真的难查。

注意区分三兄弟：`NULL` 是空**指针**，`'\0'` 是空**字符**（值为 0 的字符），`0` 是数字零。写字符串结尾用 `'\0'`，写空指针用 `NULL`，别串。

### 6. 实战：让函数"返回"多个值

学了半天，指针到底有什么用？第一个实际用途马上就来。

JS 里函数想带回多个结果很简单，返回个数组或对象就行。C 的函数只能 `return` 一个值，而且没有对象字面量。想让函数给你带回两个结果，怎么办？

答案是：**把变量的地址传给函数，让函数顺着地址往里写。**

```c
#include <stdio.h>

/* 参数是两个"指向 double 的指针" */
void get_xy(double *x_p, double *y_p)
{
    *x_p = 1.0;   /* 顺着地址写回 1.0 */
    *y_p = 2.0;   /* 顺着地址写回 2.0 */
}

int main(void)
{
    double x, y;
    get_xy(&x, &y);                    /* 把 x、y 的地址传过去 */
    printf("x=%.1f, y=%.1f\n", x, y);  /* x=1.0, y=2.0 */
    return 0;
}
```

为什么传值不行？因为 **C 语言的参数传递永远是"复制"**：把值复制一份给函数的形参，函数里改的只是那份副本，原件纹丝不动。

![值传递 vs 传指针：副本改不到原件，地址才能写回](/assets/images/c-pointers/cptr-01-call-by-value.png)

传指针时，复制的虽然也只是"地址"这个值，但**副本和原件指向同一个变量**——函数顺着地址写，就写到了调用方的变量上。

这就是为什么 `scanf` 要写成 `scanf("%d", &n)`：`&n` 把 n 的地址交给 scanf，它才能把读到的数写进你的 n。现在你不仅知道要加 `&`，还知道为什么了。

### 小结

- 内存是带编号的储物柜，编号就是地址；变量住在里面，占几格由类型决定
- 指针是专门存地址的变量；`int *p` 读作"指向 int 的指针"
- `&x` 取 x 的地址；`*p` 摸到 p 指向的变量，可读可写
- 声明里的 `*` 是类型标记，表达式里的 `*` 是解引用运算符，两码事
- NULL 表示"哪儿也不指"，用它初始化指针能让 bug 当场现形
- C 只有值传递；想让函数写回调用方的变量，就把变量的地址传过去
